# Go 注释硬约束

注释只补充代码、命名与类型无法表达的信息。必须英文、精简；一句说清时禁止多句。必须同时遵守 `code-style.md`。

## 必须写

- 业务规则、历史兼容、外部协议、特殊单位、性能/幂等/事务/缓存/并发边界、危险副作用、不可从名称推导的契约。
- 字段额外语义（如状态优先级、毫秒时间、`0` 的特殊含义）。

## 禁止写

- 中文注释；标识符复述与显然控制流，例如 `// GetUser gets the user`。
- 见名知义的字段/函数/类型；Model 常规字段：`ID`、`UniqueID`、`Name`、`Status`、`CreatedAt`、`UpdatedAt`、`DeletedAt`。
- 与代码重复、同约束多遍、过期无约束、可用改名/抽变量/拆函数表达的内容。

## 门禁

- 删掉后不影响理解业务约束的注释必须删除。
